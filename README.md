🚀 Overview

RAAJ Modules is a high-performance collection of Magisk modules engineered for real-world Android optimization.
Focused on low latency, stable FPS, and system responsiveness — not synthetic benchmarks.

---

🔥 Core Modules

⚙️ KernelEnhancer

- Advanced CPU governor tuning
- I/O scheduler optimization
- VM & memory management tweaks
- GPU throttling control
- ZRAM & kernel parameter tuning

---

🎮 GameEnhancer

- Automatic game detection
- Dynamic performance mode switching
- Real-time scheduling ("SCHED_FIFO")
- "renice" priority boosting
- Lag reduction & FPS stabilization

---

✋ TouchEnhancer

- Touch latency reduction
- UI responsiveness boost
- Real-time input prioritization
- Smooth animation tuning

---

🌐 NetworkEnhancer

- Congestion control optimization
- Reduced ping & jitter
- Stable gaming network performance

🛠️ Installation Guide

📌 Requirements:

- Rooted device
- Magisk installed
- Android 9 or above

---

📥 Steps:

1. Download desired module ZIP
2. Open Magisk App
3. Go to Modules
4. Tap Install from Storage
5. Select ZIP file
6. Reboot device
